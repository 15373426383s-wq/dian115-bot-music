# 拾音 Music · DIAN115 插件

以苹果播放器和 Liquid Glass 为视觉方向的多音源音乐下载器，独立移植 music-dl 的下载业务。当前版本 1.2.0，要求实际部署支持插件 API 3.9 的 DIAN115；不调用 Python、命令行下载器或独立后端服务。

界面文案已在 1.2.2 统一使用“标准解析 / 自定义音源”等功能名称，来源说明仅出现在设置页底部。内部协议标识和已存设置兼容不变。

## 优化版部署（本仓库源码）

- 源码仓库：https://github.com/15373426383s-wq/dian115-bot-music
- 优化内容：下载任务资料库写入节流（每 10 首落盘 + 结束强落盘）、已完成路径集合增量维护、播放凭证上限对齐 32；版本 1.2.0，保留 `requires.api: 3.9`。
- 本地校验：`node optimize-check.mjs`（mock ctx 冒烟测试，9 项）。打包：`pack.mjs`（来自 dpd 技能公开契约）。
- 在 DIAN115 插件中心安装 `release/bot.dian-music-1.2.0.dian115p` 后，可在宿主用 `POST /api/extensions/v3/bot.dian-music/jobs/query`（必填 `business_key`）触发 `action:capabilities` 做无副作用冒烟验证。

## 安装与使用

通过插件中心安装或更新 `bot.dian-music-1.2.0.dian115p`，启用后打开拾音 Music。更新保留已保存偏好和资料库记录，百度旧接口、虾米及其凭据从新设置中移除。

搜索歌名与歌手 → 选择音源/筛选 → 勾选保存，或点击“保存并播放”。网易云支持官方单曲/歌单链接，酷狗支持官方歌单分享链接。下载管理显示宿主上报的接收字节、总量（已知时）和速度，以及批次完成/失败数量。全部失败时任务失败；部分失败显示“部分完成”，可单独重试失败项目。

点击“聆听偏好 → 选择目录”使用宿主路径浏览器。选择宿主目录或 CD2 实际挂载目录后，HTTP save_to 直接流式落盘，歌词与封面保存在同一目录；不再先保存完整插件副本再复制。未选择目录时保存到插件自有 downloads。已知同名文件使用“歌手 - 歌名 (1)”等递增编号。卸载插件会清除插件文件，宿主/CD2 文件保留。

单文件默认不设置大小上限（max_bytes=0），超时默认 3600 秒；高级设置可调整大小上限和 60–86400 秒超时。音频数据不通过脚本字符串或 Base64 缓冲。每批 1–200 首。写入前后保存检查点；未知结果先核对，无法确认则保持待核对，不覆盖已有文件。

## 解析模式与自定义音源

聆听偏好提供标准解析、兼容回退、自定义音源。标准解析沿用 music-dl 的 QQ 匿名 UIN、格式顺序、网易云码率、酷狗 hash 与咪咕参数；有账号 CK 时使用自己的身份。兼容回退会尝试 QQ/酷狗网页接口。旧接口和歌曲权限仍由上游决定。

自定义音源是脚本提供的服务集合，不等于内置音乐平台。导入 `.js` 或脚本原始链接后，按初始化声明保留每个入口的标识、名称、类型、动作和音质，包括独立曲库。设置中可以选择要搜索的入口；提供 `musicSearch` / `search` 的入口直接由同一脚本搜索。只有仅提供取链且已有配套适配器的 wy/tx/kg/mg/kw 入口，才使用对应的内置曲库搜索；未知入口不会套用其他平台的搜索或 ID。

搜索结果保留完整原始歌曲数据和字符串 ID，绑定脚本 ID、原文哈希及曲库标识。取链、歌词和封面始终回到所属脚本，切换全局模式或音源不改变已有歌曲的来源。脚本更新导致哈希变化时要求重新搜索。支持的动作包括 `musicSearch`、`search`、`musicUrl`、`lyric`、`pic`；其他声明明确显示为未支持。音质按脚本原始令牌传递；实际音频格式以流式探测响应和地址为准。

源库最多 8 份，原文最大 512 KiB，加密保存在插件 KV。原始文件与 SHA-256 始终保留。页面 Worker 对严格识别的 RC4 字符串表、有界轮转和对应启动自校验做静态展开，不执行用户函数；界面显示处理摘要。其他脚本只做 Babel ES5 转译。用户提供的全豆要 v4.0 原文件已完成编译和六个入口初始化验证，无需手工提供修改版。脚本及其中的服务密钥不进入发行包。

支持 Promise / async、HTTP 回调、Buffer、MD5、AES-ECB/CBC、1024 位 RSA_NO_PADDING、zlib 和有界定时器。隔离环境不提供 DOM、Node 模块、WASM、BigInt、formData。复杂正则受限：输入最多 8192 字符，拒绝分组重复、回溯引用、环视和多重不定重复。每次动作最多 180 秒 / 400 万解释步骤；单次接口响应、字节数组和解压结果最多 512 KiB；HTTP 最多并发 6 个、每个解释器 40 次，单请求最多 60 秒。取消会抑制回调，返回前仍等待已发出的原生网络操作结束。上述限制不限制音频文件大小。

脚本没有账号 CK、CookieCloud、宿主文件或设置权限，使用独立网络会话。返回地址后先检查实际音频响应，错误页、JSON 和分段播放清单不能成为成功的音频文件。下载继续使用宿主原生流式保存及落盘播放。仅导入可信脚本；初始化成功、返回网址和实际可下载分别验证。协议参考：https://lxmusic.toside.cn/desktop/custom-source 。

## 音乐账号与 CK

在聆听偏好的独立 CK 面板选择网易云、QQ、酷狗或咪咕：

- “读取 CookieCloud”：使用宿主已配置并同步的 CookieCloud，按所选站点读取。QQ 读取共享 qq.com 域后筛除非音乐子域；其他站点限定各自音乐域。
- “读取插件会话”：读取本插件对应音乐会话中当前可用的 Cookie，不读取浏览器登录凭据。
- 手动粘贴一行 `name=value; name2=value2`，也接受带 `Cookie:` 前缀的请求头。默认隐藏，可按需显示；可清空。

读取和填写先进入偏好草稿，点击“保存偏好”后生效。CookieCloud 的域、路径、Secure、HttpOnly 和有效期等属性保留；手动编辑后按新的请求头导入。新任务会同步本站独立会话，清空后不继续使用旧 CK。凭据保存在插件加密 settings，不输出日志、不回写 CookieCloud、不请求 115 Cookie。读取到 CK 不等于账号登录或会员权限已经验证。

## 下载与播放

音源地址通过所选模式解析；需要探测的候选使用流式 GET 读取响应头并关闭上游，避免 HEAD 不兼容，也不把完整音频读入内存。支持音质候选和公开网页接口回退。

点击歌曲或“播放全部”可直接在线听，不会创建下载任务、保存音频或加入资料库；点击保存图标才下载。已保存歌曲优先使用本地文件。在线播放通过宿主登录鉴权的私有流式接口，逐块转发音频与 Range 请求，支持暂停、切歌、进度拖动、音量和同步歌词。歌词独立获取，不阻塞音频开始。脚本歌曲始终使用所属脚本和原始字段取链。播放凭证随机生成并加密保存在插件 KV，最多 32 个，有效期两小时；过期或上游地址失效后点击播放重试。上游需支持相应范围读取，浏览器仍需支持该音频格式；无转码功能。在线听会跳过已知不适合浏览器的 APE，下载格式策略保持不变。

解析、缓冲和失败重试有明确提示。浏览器阻止异步自动播放时提示再点一次播放。播放列表支持逐首解析，快速切歌会取消旧解析并忽略旧结果。下载完成自动播放仍是独立可选偏好。

资料库通过宿主登录鉴权和 Range 的文件地址播放，歌词按同一路径读取。下载管理只显示下载批次；移除记录任务不再混入队列。旧版、部分完成和无结果的任务均按成功/失败数组归一化，避免缺失字段造成整个页面空白。

从资料库移除宿主版本时仅移除记录，实际文件保留；移除插件自有版本需要再次确认，只清理 downloads 内的音频、歌词和封面。旧版导出的宿主副本也保留。

## 音源范围

保留网易云、QQ、酷狗、咪咕；酷我作为需 LX 取链的扩展搜索平台。移除百度旧接口和虾米适配器、配置入口与新请求。QQ/酷狗公开搜索可用不代表匿名下载可用，CK 和会员/地区权限仍由上游判断。咪咕修复原协议参数并使用 GET 探测，本轮只读实网检查有候选返回真实 audio/mpeg，也有候选返回业务错误；不承诺所有歌曲或音质可用。

搜索结果聚合、按歌手/歌名去重并优选大文件、替代音源、size/length 组合筛选、收藏、歌词封面和歌单分页均保留。页面提供珍珠白/午夜主题、透明度选项、桌面侧栏与手机底栏。没有远端字体、脚本或生成图片依赖。

## 开发与验证

Node.js 22.18+。`npm ci` → `npm test` → `npm run build` → `npm run check` → `npm run package`。

`npm run dev` 是明确标记的界面预览，使用开发夹具，包括模拟 CK、文件与下载；不读真实 CookieCloud，不保存真实音乐，不能代表实际音源成功。预览、测试、node_modules、浏览器记录和截图不进入发行包。真实业务验证范围见 VALIDATION.md。
