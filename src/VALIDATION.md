## 本轮下载页与在线聆听

复现真实宿主下载页面 TypeError：资料库移除任务 result 为 {removed:true}，界面误读 failed.length。结果数组归一化，移除任务从下载队列排除，保留活动移除任务的并发保护。旧版无结果、仅部分数组、失败与检查点结果都有回归检查。

增加私有流式在线聆听：点击歌曲不启动下载任务，不写音频和资料库；同源登录鉴权，随机播放凭证绑定已验证的媒体 URL，单区间 Range/If-Range，逐块读写，连接结束与异常都关闭上游。不会透传浏览器 Cookie/Authorization 或上游 Set-Cookie。播放原生音源与独立曲库的来源隔离保留。新增在线场景跳过 APE 的检查，下载原版参数测试保留。

77 项本地测试通过。在线流式读取不受 JSON 接口响应大小限制，且不预先缓冲完整文件。桌面和手机的队列、错误重试、播放与进度拖动由 Playwright 检查；真实宿主安装后证据另存 output/validation，不打入包。

## 安全扫描逐项审查

官方检查器输出 needs-review，没有 do-not-install。敏感项用途已在 declared_usage 声明：

1. jobs/manage.js 的删除调用只允许已确认的插件 downloads 文件；宿主/CD2 文件移除只删除索引，已有测试覆盖。
2. lib/credentials.js 与页面中的 Cookie+网络：按音乐站点过滤、独立 music-* 会话；不读取其他插件或 115 Cookie。
3. lib/credentials.js 与页面中的 CookieCloud：用户主动 read，保留安全属性、不 write。
4. lib/netease-crypto.js 长十六进制是公开 WEAPI RSA 模数；新增 RSA PEM 解码仅用于数据加密。
5. lib/lx-engine.js 大量转义是所捆绑 JS-Interpreter / Acorn 的解析器与 ES5 内建 polyfill；源码由固定 npm 版本构建，未使用 Node VM，按步骤解释客体代码。
6. ui/page.js 的混淆+网络组合源于内联 Babel 编译 Worker 与已有 HTTP/CK 调用处于同一个打包文件。编译 Worker 只转译，不执行用户源；客体只在隔离解释器运行。没有远程脚本加载。
7. ui/page.js 的零宽字符来自 Babel 的 Unicode 标识符合法字符表（U+200C / U+200D），不是隐藏指令或通信；所用 npm 许可证和原始出处见 THIRD_PARTY_NOTICES。

解释器桥接只提供 LX 协议、受限 HTTP、Buffer 与密码学；无宿主 ctx、设置、文件、CookieCloud、原生 Function/eval 暴露。网络拒绝内网字面量和保留域、逐跳校验重定向，不能替代宿主 DNS/网络出口策略。脚本源码与转译结果存在插件加密 KV，输入任务只传 ID，不将整份脚本写入任务输入或日志。主动链接导入的获取结果会经过任务结果返回给页面。
